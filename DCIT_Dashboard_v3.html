How to get your Web App URL
  1. Open your Google Sheet
  2. Click Extensions → Apps Script
  3. Paste the DCIT_Apps_Script.gs code and save
  4. Run the setup() function once
  5. Click Deploy → New Deployment
  6. Type: Web App · Execute as: Me · Access: Anyone
  7. Click Deploy → copy the URL → paste above
