Connection Setup
Connect this dashboard to your Google Sheets Web App.
Google Apps Script Web App URL

After deploying the DCIT_Apps_Script.gs file, paste the Web App URL here. All data will sync in real time.

How to deploy the Apps Script
  1. Open your Google Sheet → Extensions → Apps Script
  2. Paste the entire contents of DCIT_Apps_Script.gs and save
  3. Click ▶ Run → choose the setup() function → Authorize when prompted
  4. Go to Deploy → New Deployment
  5. Type: Web App · Execute as: Me · Access: Anyone
  6. Click Deploy → copy the URL → paste above → Save Settings
  7. Each employee gets their own attendance tab automatically on first save.
